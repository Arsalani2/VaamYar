## 📖 درباره برنامه

**وام‌یار** برای حل یکی از متداول‌ترین دغدغه‌های مالی افراد طراحی شده است: **مدیریت شفاف چندین وام هم‌زمان، تفکیک سهم شرکا و پیگیری مطالبات ماهانه**.

بسیاری از افراد برای دریافت وام‌های بانکی یا خانوادگی، با دوستان و اعضای خانواده شریک می‌شوند. در چنین شرایطی، دانستن اینکه:
- چه مبلغی سهم واقعی خودتان است،
- چقدر از اقساط پرداخت شده و چقدر مانده،
- هر شریک در این ماه چه مبلغی بدهکار است و چه کسانی واریز کرده‌اند،
به محاسبات پیچیده و یادداشت‌های دستی نیاز دارد. وام‌یار تمامی این فرآیندها را به صورت خودکار، دقیق و زیبا انجام می‌دهد.

## ✨ امکانات و قابلیت‌های کلیدی

### ۱. داشبورد اقساط (صفحه اصلی)
- **محاسبه هوشمند سهم مبنا:** نمایش برجسته مانده پرداخت‌نشده سهم شما در ماه جاری.
- **۳ حالت نمایش کارت‌ها (ماندگار):**
  - **مستطیلی (تفصیلی):** مشاهده ریز جزییات هر وام، شرکا، سررسید و پیشرفت اقساط.
  - **مربعی (فشرده):** چیدمان گریدی شیک برای مرور سریع ده‌ها وام در یک نگاه.
  - **نموداری (دایره‌ای):** نمایش ماه‌های شمسی داخل گره‌های دایره‌ای با رنگ‌بندی تفکیک‌شده اقساط پرداخت‌شده.
- **تغییر وضعیت سریع پرداخت:** امکان علامت‌گذاری پرداخت ماه جاری با یک لمس همراه با بازخورد صوتی و لرزشی.

### ۲. تقویم شمسی یکپارچه و دقیق
- **محاسبه خودکار اقساط گذشته:** با انتخاب تاریخ شروع وام، برنامه به صورت هوشمند تشخیص می‌دهد تا تاریخ امروز چند قسط سررسید شده است.
- **تقویم مجازی مینیمال:** انتخاب آسان سال، ماه و روز شروع وام در یک دیالوگ زیبا.
- **همگام‌سازی تاریخ:** امکان تنظیم خودکار بر اساس ساعت سیستم یا تعیین تاریخ دستی جهت تست و شبیه‌سازی در تنظیمات.

### ۳. مدیریت مطالبات و شرکا
- **تفکیک خودکار سهم شرکا:** تجمیع مطالبات هر شخص در تمام وام‌ها در یک کارت اختصاصی.
- **ارسال یادآوری پیامکی و متنی:** تهیه متن آماده، مودبانه و با ارقام دقیق جهت ارسال در پیام‌رسان‌ها یا SMS.
- **چک‌باکس وصول ماهانه:** علامت‌گذاری مبالغ دریافت شده از هر شریک با امکان ریست ماهانه.

### ۴. مدیریت هوشمند کاربران
- **راهنمای آغازین (Onboarding):** راه‌اندازی بدون نیاز به ثبت‌نام یا اطلاعات حساس؛ تنها با وارد کردن نام کاربر مبنا.
- **حذف امن کاربران:** جلوگیری از حذف کاربری که در وام‌های فعال سهم دارد تا زمان تعیین تکلیف شراکت.
- **همگام‌سازی دوطرفه:** ویرایش نام یا شماره کاربر، تمامی مطالبات و وام‌های مربوط به او را فوراً به‌روزرسانی می‌کند.

### ۵. دستیار مالی هوشمند
- الگوریتم هوشمند پیشنهاد گلوله برفی (Snowball) برای تسویه سریع‌تر وام‌های رو به پایان.
- هشدار خودکار نزدیک شدن به سررسید اقساط و پیگیری مطالبات معوق با فرمت ارقام خوانا (`۲,۸۰۰,۰۰۰ ریال/تومان`).

### ۶. شخصی‌سازی و رابط کاربری مدرن (Material 3)
- پالت‌های رنگی جذاب (سبز زمردی و طلایی، آبی لاجوردی، ارغوانی نئون و ...).
- پشتیبانی کامل از حالت تاریک (Dark Mode) و روشن (Light Mode).
- فونت‌های بهینه‌شده فارسی و امکان سوئیچ ارقام فارسی/انگلیسی.

## 🏗️ معماری و فناوری‌ها

- **زبان:** Kotlin
- **چارچوب رابط کاربری:** Jetpack Compose با سیستم طراحی Material Design 3 (M3)
- **پایگاه‌داده محلی:** Room Persistence Library (SQLite آفلاین و امن بدون ذخیره ابری اطلاعات هویتی)
- **مدیریت حالت (State Management):** Android ViewModel + Kotlin Coroutines & StateFlow
- **معماری:** MVVM (Model-View-ViewModel) با تفکیک لایه‌های Data ،Model و UI
- **تست‌ها:** Robolectric Local JVM Tests برای تست منطق و دیتابیس

## 🚀 نحوه اجرا و بیلد پروژه

### پیش‌نیازها
- **Android Studio Ladybug** یا نسخه بالاتر
- **JDK 17** یا بالاتر
- **Android SDK:** حداقل نسخه ۲۶ (Android 8.0) و نسخه هدف ۳۵

### مراحل اجرا
۱. مخزن را کلون کنید:
```bash
git clone https://github.com/your-username/vamyar.git
cd vamyar
```

۲. پروژه را در **Android Studio** باز کنید و اجازه دهید فرآیند Gradle Sync کامل شود.

۳. برای اجرای تست‌های واحد در ترمینال:
```bash
./gradlew testDebugUnitTest
# یا در محیط لینوکس/CI:
gradle :app:testDebugUnitTest
```

۴. برای ساخت فایل خروجی APK:
```bash
./gradlew assembleDebug
```
